# Worksheet: weekly-review, ten minutes to see what moved and what repeated

## When to use it

Once a week, at a fixed time you pick (Friday afternoon or Sunday night work well). It takes ten minutes.
Skip a week without guilt; do not skip two.

## What Claude does with it

Claude reads the week's diary, pains and tasks, then proposes answers to the first four rows from what is
written there. You correct them. It only saves what you confirm. Patterns that repeat three times become a
proposal for a skill or a rule, never a change made on its own (see the `task-observer` skill).

## Fields

| field | question | your answer |
|---|---|---|
| moved | Which project advanced, and what is the proof (a file, a commit, a person)? | |
| stuck | What did not move, and why, in your words? | |
| pains heard | Which new pains did you log? Count them: [[worksheets/pains]]. | |
| decisions | Which choices did you make? Log them: [[worksheets/decisions-log]]. | |
| repeated | What did you do by hand more than twice? | |
| next week | The one project and the one next step. | |
| energy | One word, only if you want to track it. | |

## Rules

1. **Evidence over feeling.** "Moved" needs a file or a person, not "I think so".
2. **One project for next week.** Two is a wish list.
3. **Do not grade yourself.** The review describes the week; it does not give it a score.
