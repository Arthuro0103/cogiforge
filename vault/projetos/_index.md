# Projetos

**Regra de admissão:** todo projeto aparece nesta tabela, com pasta própria em `projetos/<nome>/` e
um `instrucoes.md` como raiz. Projeto fora da tabela não existe para a bancada.

| projeto | status | tipo | o que é |
|---|---|---|---|
| [[projetos/exemplo-meu-primeiro-projeto/instrucoes\|exemplo-meu-primeiro-projeto]] | ativo | exemplo | Modelo para copiar. Apague a linha e a pasta quando criar o seu primeiro projeto. |

Status possíveis: `ativo`, `pausado`, `encerrado`. O tipo é livre (software, escola, trabalho, pessoal, escrita...).
