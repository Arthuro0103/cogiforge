# Template: why this project exists and for whom

delete this paragraph. Every answer is the person's own words, in quotes, with the date. A field with no answer
stays empty. The skill that fills it is described in `.claude/skills/cf-brand/SKILL.md`, and it is listed in the
[[skill-worksheets/_catalog|catalog]].

`[[projects/<name>/instructions|<name>]]`". The DNA extends the product brief (`projects/<name>/product.md`):
link it instead of repeating what it already says.
